# GMSFAN
the code for Gated-Multi-Scale Feedforward-Attention Network.
All datasets used in this study for model pretraining, training and evaluation are available at https://doi.org/10.5281/zenodo.21287653(Du et al. 2026).
Use train_4x.py for model training and use eval_4x.py for evaluation.
Models were saved in model_archs.zip.
